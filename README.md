# ⚽ Football Mystery Draft Game

## 🚀 Overview

Football Mystery Draft Game is an interactive football simulation game where players build their teams through a unique drafting system that mixes **strategy, randomness, and hidden information**.

Unlike traditional draft games, players must make decisions with **partial knowledge**, creating a more exciting and unpredictable experience.

---

## 🎮 Features

* 🧠 **Mystery Draft System**

  * Choose players without knowing their full identity
  * Strategic guessing and risk-taking

* ⭐ **Featured vs Mystery Picks**

  * Featured Player → visible selection
  * Mystery Player → hidden until revealed

* 👥 **Multiple Game Modes**

  * Single player (vs AI)
  * Local multiplayer (2 players)
  * (Planned) Online multiplayer

* 📊 **Team Building Logic**

  * Balanced squad creation
  * Position-based drafting

* 🎯 **Match Simulation**

  * Simulate matches based on team strength
  * AI-driven outcomes

```bash
npm run dev
```

## 🎯 How to Play

1. Start a new game
2. Choose draft mode
3. Pick between:

   * ⭐ Featured Player (safe choice)
   * ❓ Mystery Player (risky choice)
4. Build your team
5. Simulate the match
6. See results and compare teams
